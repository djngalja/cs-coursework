# PostgreSQL Bootcamp: 12 mini-projects
Mini projects aimed at building my SQL skills.

## My setup
- VS Code + SQLTools extension + SQLTools PostgreSQL/Cockroach Driver
- Oracle VirtualBox + Ubuntu 24.04.4 LTS + psql 16.13

## Projects
1. __SQL basics:__ SELECT, FROM
2. __Retrieving data:__ subqueries, sorting, various types of JOINs
3. __Retrieveing data:__ handling NULL-values, common table expressions (CTEs)
4. __DML:__ INSERT, UPDATE, DELETE
5. __SQL Views__
6. __Recursive Join in SQL__
7. __Database indexes__
8. __Constraints__
9. __Aggregating information__
10. __Isolation levels__
11. __Functions and triggers:__ SQL, PL/SQL functions
12. __Dealing with data from different sources__
